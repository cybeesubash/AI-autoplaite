About the Project

Indian Vehicle Registration Intelligence

AutoPlate AI is an advanced automated number plate recognition (ANPR) and public information retrieval framework developed specifically for Indian traffic ecosystems. It handles standard high-security registration plates (HSRP), vintage formats, commercial yellow plates, and electric vehicle green plates.

  • ✓ High-confidence plate localization from single photos or continuous video
  • ✓ Automated RTO district decoding (e.g., TN-38 Coimbatore, KA-01 Bangalore)
  • ✓ REST API microservice architecture with async multi-query search
  • ✓ Privacy-preserving public lookup without exposing personal citizen records

AutoPlate AI is an academic research and engineering demonstration system developed for AI-based Indian vehicle number plate detection, OCR recognition, and public registration area lookup.
